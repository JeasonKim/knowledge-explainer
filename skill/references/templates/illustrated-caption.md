# 插画字幕

`illustrated-caption` 是知识讲解方法下的插画字幕表达。画面由账号标记、主题封面、两行字幕区、插画槽、主题收束页、免责声明和页脚组成；制作单只提供本期内容和已登记资源 ID。

## 视觉表达

- 主题封面使用“双层命题”：保留标题原文，黑色粗体表达主命题，朱红粗体表达强调命题。没有自然切点时只做均衡视觉分行，不改写标题。
- 正文始终显示一至两行无标点语义字幕，并在固定插画槽展示当前 `illustrationCueId` 对应的插画。
- 首帧使用第一组字幕的插画，收束页使用最后一组字幕的插画。插画必须来自当前视觉系统并已通过素材审核。
- `portrait-3x4`、`vertical-9x16` 与 `landscape-16x9` 只改变确定性视图几何，不改变内容、音频或时间图。
- 账号页脚固定为三栏两行：每栏表达一组账号定位，上下两行共同组成完整短语；字段数据不直接作为带分隔符的原始文字显示。

## 字幕容量

- `caption` 只允许一至两行，每行必须是完整词语、短语或句子。
- 禁止显示中英文 Unicode 标点，禁止按固定字数批量换行，禁止拆开完整词语。
- 字幕超出容量时重写口播或重新划分卡片，不通过缩小字号解决。
- TTS 和 ASR 使用自然标点且不含展示换行的 `spokenText`；画面只使用 `caption`。

## 插画母版

没有直接匹配的插画时，生成一张三列两行母版，再调用 `ingest-illustration-sheet` 切分、归一化和登记。每格只包含一个独立视觉隐喻，不出现文字。

```text
请生成一张用于知识视频的插画资产母版，不是海报，不出现文字。

整体风格：{系列插画风格}
画布：横向 3:2，严格分为三列两行六个等大格位。
背景：所有格位使用高纯度 #00FF00 绿幕；插图内禁止使用接近该颜色的绿色。
每格只放一个独立视觉隐喻，主体、阴影和线条均留在本格内，四周留安全边距，不跨格、不连接。
每个主体形成紧凑、完整的视觉轮廓；避免细长竖条、极扁横条和局部角落构图。
禁止文字、数字、标志、水印、边框、界面、复杂背景、写实摄影、渐变和三维渲染。

六个格位依次表达：{视觉隐喻 1}、{视觉隐喻 2}、{视觉隐喻 3}、{视觉隐喻 4}、{视觉隐喻 5}、{视觉隐喻 6}。
```

```bash
RUNNER="<skill-root>/scripts/run-project.sh"

"$RUNNER" ingest-illustration-sheet \

```

## 时间与验收

- 主题封面固定为 0.5 秒；24 FPS 对应 12 帧。口播从封面结束后立即开始。
- 收束页固定为 1.25 秒，从口播结束后开始，不能侵占或截断口播。
- 真实第 1 帧直接完整显示封面，不做淡入；真实最后 1 帧完整显示收束页，不做淡出到空白。
- 首尾帧都必须包含可读标题和语义匹配的已登记插画。
- 质量门禁必须拒绝字幕与口播不一致、字幕残留标点、机械等长切分或时间轴越界的作品。
